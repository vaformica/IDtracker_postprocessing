## Turtling recommendation

The current detector should remain a labeled baseline until comparison against reviewed video. Code inspection and a synthetic counterexample demonstrate that its cumulative absolute turning can count repeated reversals as rotations: a straight-line back-and-forth path was labeled for all 120 frames despite no circles. Tight threshold gates can also reject a full window because of one large step. Candidate windows can blur behavioral boundaries.

Use the random pilot for workflow checks and deliberately selected known bouts/lookalikes for calibration. Label inverted posture and active flailing separately. Test on held-out whole source videos and report event recall, false alarms, and duration error independently. Quiet overturned pauses require an explicit duration definition. See [the detector review](BA_TURTLING_DETECTOR_REVIEW_2026-09-29.md). No new classifier has been validated or substituted into the pilot.
