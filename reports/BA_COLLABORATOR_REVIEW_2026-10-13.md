# Reviewing the frozen BA tracking batch

This review helps decide which single-beetle runs are usable and which need closer attention. You do not need to describe every small imperfection. The priority is major wrong-object tracking, large jumps, and prolonged losses that could materially affect analysis.

Extract the whole BA_frozen_221_QC ZIP and open START_HERE.html. Enter your name. The list starts with higher-priority runs; use the remaining-jumps or missing-tracking filters if helpful. Traces appear automatically. Orange points are interpolated, blue points retain the baseline, and purple video markers show earlier recovery proposals. The original overlay is available for comparison.

For each run:

1. Skim its full trace. If it looks plausible, record “Looks usable” with coverage set to “Trace skim.” This does not certify unseen frames.
2. If something looks wrong, jump to that scene or watch the full video. Controls and frame numbers are below the image.
3. Select the closest issue category and “Needs attention,” “Unsure,” or “Recommend exclusion.” A brief note is optional. Include a global frame only when it helps locate something unusual.
4. Download ALL scores periodically and before closing. One JSON contains your decisions across the batch. Return that file; keep your copy. Each reviewer should use their own name and export.

The review never changes tracking or excludes a beetle automatically. Blank runs remain unreviewed. Exclusion recommendations need a later decision. Existing scores from older viewers do not automatically approve this new coordinate version.

The method intentionally leaves long or unsupported gaps missing. Only BA single-animal recordings receive this interpolation. Deliberately excluded lighting frames remain unknown. Turtling is not assessed here; do not use interpolation as posture evidence.
