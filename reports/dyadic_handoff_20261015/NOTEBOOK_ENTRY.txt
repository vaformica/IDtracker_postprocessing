The next scientific discussion is the variable definition and export contract. Core outcomes are displacement-onset latency, time near the wall, time on each fungus and any fungus, total distance, distance within the wall zone, distance on fungus, observed proximity duration and proximity interactions. Suggested additions are first proximity/fungus-entry latency, complete-bout median and maximum duration, pair distance, region visits, and explicit coverage/jump diagnostics. Posture/turtling, directed aggression and initiator/leaver remain separate unvalidated extensions for dyads.

Current code definitions matter: movement latency is the first 30-pixel displacement from the exact analysis-entry coordinate reached through an uninterrupted sequence of accepted steps. It is not automatically first limb movement or righting. Wall distance is accepted 2-D path distance allocated by step midpoint within the wall zone, not perimeter distance. Assigned-centroid proximity is <=60 original-image pixels. PSC is separately inferred only for missing IDs with compatible evidence. Raw and PSC summaries use different default jump cutoffs (200 versus 100 pixels per step); comparisons must record those settings. Unknown frames cannot be treated as apart, off-fungus or stationary.

The proposed schema separates source recordings, physical trials/cells, IDtracker attempts, processing attempts, biological-ID mappings, windows, animal/window summaries, region summaries, pair/window summaries, bouts, frame evidence, review decisions and artifact hashes. Primary and foreign keys prevent reruns from being counted as new trials. Each result retains exact video/TOML/cell identity, trajectory source kind, ROI definition, recording metadata and calibration; software versions and actual code hashes; independent IDtracker and processor start/completion dates with evidence sources; parameters; and attributed metric-specific review status. Missing historical dates or versions remain unknown rather than being inferred from file modification times.

Verified local versions are PSC engine 1.6.0, shared group processor 0.8.2-group and legacy/base processor 0.8.1; per-run deployed versions must still come from manifests and frozen code. The proposed schema 0.1 is not yet an implemented exporter. The report marks existing, derived and new fields separately and specifies units, denominators, inclusive frame conventions, censoring, identity joins and QC checks. Full windows have 7200 observations; the underlying group window parameter counts intervals, so off-by-one conversion must be checked.

Before extraction, agree on time origin/latency, fungus tracing and boundary inclusion, primary windows, proximity-bout splitting and unknown boundaries, physical calibration, and metric-specific acceptance tolerances.
